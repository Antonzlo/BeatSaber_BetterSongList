# Difficulty-Per-Difficulty Expander (PoC)

Этот проект — PoC: расширяет список песен BetterSongList, так чтобы каждая доступная сложность песни отображалась как отдельная строка.

Цели:
- Сделать так, чтобы в списке каждая сложность была собственной записью.
- Минимально вмешиваться в BetterSongList, использовать его публичное поле `HookLevelCollectionTableSet.sorter`.

Требования к сборке:
- .NET Framework 4.7.2 (или совместимая версия для модов Beat Saber).
- Ссылки на UnityEngine.dll, 0Harmony.dll.
- (Опционально) ссылки на сборки BetterSongList, если хочешь компилировать с интерфейсами.

Сборка и установка:
1. Склонируй репозиторий и создай ветку `difficulty-expander`.
2. Настрой проект в Visual Studio / Rider, добавь ссылки на Unity и Harmony.
3. Собери DLL и помести её в папку модов (в зависимости от загрузчика).
4. Запусти игру и проверь логи.

Примечания:
- Код реализован через reflection/DispatchProxy, чтобы минимизировать жёсткие зависимости от версий.
- После установки проверь, не конфликтует ли поведение с другими модами, которые тоже меняют sorter/filter BetterSongList.
